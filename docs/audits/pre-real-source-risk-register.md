## Severity policy

- HIGH: can expose private network/data, silently invalidate recommendations,
  cause uncontrolled resource use, or make a controlled pilot unsafe; blocks
  readiness while open.
- MEDIUM: material correctness, integrity, operability, reproducibility, or
  defense-in-depth issue requiring disposition before pilot.
- LOW: bounded usability, maintainability, diagnostics, or documentation issue
  with a safe workaround.

## Readiness effect

PRS-002 is fixed for all runtime HTTP traffic. PRS-003 and PRS-020 remain
unimplemented for external browser extraction, but that feature is blocked at
configuration, readiness, and renderer boundaries and is outside the controlled
HTTP-only pilot exposure. Complete verification and Node 22/npm 10 evidence now
pass, closing PRS-012. No open HIGH risk is exposed by the restricted pilot.
